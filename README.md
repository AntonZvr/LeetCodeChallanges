Problem Description
Given an array nums of size n, return the majority element.

The majority element is defined as the element that appears more than ⌊n / 2⌋ times. This means it appears strictly more than half the time.

You may assume that the majority element always exists in the array. This is a crucial guarantee that simplifies the problem, as you don't need to handle cases where no majority element exists.

Examples
Let's clarify with some illustrative cases:

Example 1:

nums = [3, 2, 3]
n = 3 (⌊3 / 2⌋ = 1)
Output: 3
Explanation: 3 appears 2 times, which is more than 1.
