Given a string s, determine if it is a palindrome.

A palindrome is a sequence that reads the same forwards and backward.

For the purpose of this problem, typically:

Non-alphanumeric characters (like spaces, punctuation, symbols) are ignored.
Case sensitivity is usually ignored (e.g., 'A' is treated the same as 'a').
The goal is to return true if the processed string is a palindrome, and false otherwise.

Examples
Let's look at some examples to clarify the rules:

Example 1:

s = "A man, a plan, a canal: Panama"
Output: true
Explanation: After converting to lowercase and removing non-alphanumeric characters, it becomes "amanaplanacanalpanama", which reads the same forwards and backward.
