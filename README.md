Problem Description
Given two strings, haystack and needle, return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.

For the purpose of this problem, when needle is an empty string, return 0. This is consistent with common string library functions.

Examples
Example 1:

haystack = "sadbutsad"
needle = "sad"
Output: 0
Explanation: "sad" starts at index 0 in "sadbutsad".
Example 2:

haystack = "leetcode"
needle = "leeto"
Output: -1
Explanation: "leeto" is not found in "leetcode".
